## 🏛️ Executive Summary

**Vanir Luxury Travel Web Platform** is an enterprise-grade digital experience crafted for ultra-high-net-worth individuals (UHNWI), diplomatic delegations, and discerning travelers seeking uncompromised luxury across Egypt and premier global destinations.

Designed with an **Art Deco Luxe** visual aesthetic (black and brushed gold), the platform provides seamless booking flows, real-time private aviation charters, 5-star Nile cruise itineraries, and an intelligent AI travel concierge.

---

## ✨ Flagship Capabilities

### 🌍 Sovereign Guest Experience
- **Curated Luxury Itineraries:** Pharaohs & Superyacht, Imperial Egypt, Desert Kingdoms, and Red Sea Reverie.
- **On-Demand Private Jet Aviation:** Tiered aircraft fleet specifications, hourly rate calculator, and instant booking requests.
- **Multilingual Excellence:** Native English, Arabic (RTL), and German content with dynamic typography adaptation.
- **Interactive Global Globe:** 3D WebGL globe visualizing luxury flight corridors and destinations.
- **AI Sovereign Concierge:** Intelligent multimodal agent helping guests craft bespoke custom itineraries 24/7.

### 🛡️ Unified Admin Control Suite
- **Visual Live Content Editor:** Zero-code hero banner modifications, typography adjustments, and instant previewing.
- **Luxury Fleet & Package Management:** Real-time rate adjustments, amenity toggles, and instant publishing.
- **Comprehensive Media & Gallery Management:** Local device image and video uploads with aspect-ratio optimization.
- **Enterprise Security & Role-Based Access Control (RBAC):** Strict audit logging, IDOR prevention, and sanitized server telemetry.

## 🛠️ Architecture & Tech Stack

```
vanir-web/
├── client/                     # High-performance React 19 Frontend
│   ├── src/
│   │   ├── components/         # Modular Art Deco UI system (Tailwind & Radix UI)
│   │   ├── pages/              # Luxury service routes & Admin Control Suite
│   │   ├── contexts/           # Dynamic Theme, Colors & Typography providers
│   │   └── lib/                # tRPC & Firebase client adapters
├── server/                     # Robust Node.js & tRPC Backend
│   ├── routers/                # Endpoints (Bookings, Fleet, CMS, AI, Auth)
│   ├── db.ts                   # Drizzle ORM database client (Turso / SQLite)
│   └── _core/                  # Express server orchestration & middleware
└── shared/                     # Shared TypeScript schemas, validators & constants
```

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **Package Manager**: `pnpm` (recommended)

### Installation
```bash
# Clone repository
git clone https://github.com/ahmed12345678985/vanir-web.git
cd vanir-web

# Install dependencies
pnpm install

# Run development server
pnpm run dev
```

### Production Build
```bash
pnpm run build
```
